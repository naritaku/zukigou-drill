# 要件書

配線用図記号ドリルの確定要件、スコープ、スケジュール。

## 確定要件

### 機能要件

- [x] **JIS C 0303 記号の練習**
  - スマートフォンで指描き入力
  - 記号のみの練習（説明・採点なしの基本モード）

- [x] **AI による自動採点**
  - 各記号の必須特徴・禁止特徴を観察（類似記号との弁別は禁止特徴に書き下す）
  - 決定的な合否判定（構造的にコード判定）
  - スコア算出と不足特徴の詳細フィードバック
  - 判定後に記号の名称と用途を表示（第二次検定は記号から名称・説明を答えさせるため）

- [x] **ユーザー認証なし**
  - ログイン機能不要
  - 成績保存なし
  - URL 共有だけで利用可能

- [x] **ブラウザベース**
  - モダンブラウザで動作（Chrome, Safari, Firefox）
  - レスポンシブ対応（スマートフォン・タブレット）
  - Canvas 指描きインターフェース

- [x] **API 設計**
  - `GET /api/question`: ランダム出題
  - `POST /api/judge`: 採点
  - `GET /healthz`, `GET /readyz`: ヘルスチェック

### 非機能要件

- [x] **パフォーマンス**
  - API レスポンスタイム: 2-5 秒（Gemini API 呼び出し含む）
  - ブラウザレンダリング: 100ms 以下

- [x] **スケーラビリティ**
  - Cloud Run による自動スケール
  - Scale to zero（利用なし時）

- [x] **セキュリティ**
  - ユーザー認証なし（認証リスクなし）
  - 個人情報保存なし
  - API キー保護（Secret Manager）
  - 入力検証（画像形式・サイズ）

- [x] **可用性**
  - 24/7 稼働（Cloud Run ネイティブ）
  - ヘルスチェック監視
  - 自動再起動

## 制約・リスク

### 技術的制約

| 制約 | 理由 | 対応 |
|------|------|------|
| 永続 DB なし | 判定は状態を持たずスケールさせる | レート制限状態のみ Firestore に永続化 |
| 外部 API 依存 | Gemini API の可用性に依存 | フォールバック・レート制限対応 |
| ブラウザ Canvas のみ | touch/mouse イベント対応に限定 | タッチペン完全対応は将来課題 |

### リスク

| リスク | 影響 | 軽減 |
|--------|------|------|
| Gemini API 配額切れ | 採点不可 | 複数キー・有料キーフォールバック |
| Cloud Run 再起動 | レート制限状態喪失 | Firestore にバックオフ状態を永続化して復元 |
| ルーブリック誤り | 採点ぶれ | 専門家レビュー・継続改善 |
| スパム/DoS | サービス停止 | Cloud Armor・レート制限 |
