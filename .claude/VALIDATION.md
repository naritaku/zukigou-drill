# 自動検証・テスト・改善ループ

このファイルでは、コミット前の検証プロセスを定義しています。

## 1. テスト実行

```bash
python3 -m unittest
```

**確認項目：**
- すべてのテストが合格すること
- 新機能追加時は新規テストを追加すること

## 2. ローカルレビュー実行

```bash
/local-review main HEAD
```

**確認項目：**
- MUST 指摘がないこと
- SHOULD 指摘があれば、修正するか justification を記載すること
- MAY 指摘は軽微なため、対応は任意

## 3. コミット前チェックリスト

- [ ] `python3 -m unittest` で 8/8 合格
- [ ] `/local-review` で MUST 指摘がない
- [ ] AGENTS.md の規約に従っている
  - Python ロジック変更 → テスト合格
  - JSON 変更 → JSON 妥当性確認
  - HTML/CSS 変更 → ビジュアル確認
- [ ] ドキュメントが最新か確認
- [ ] コミットメッセージは英語、PRは日本語

## 4. 自動化ループ（Claude Code 内）

以下のコマンドで、テスト → レビュー → 修正 → 再テストを自動化できます：

```bash
/loop validate-and-improve
```

このループ内では：
1. テスト実行
2. 失敗時は原因特定＆修正
3. レビュー実行
4. MUST/SHOULD 指摘を分析
5. 修正可能な指摘は自動修正
6. 最終テスト
7. コミット準備状態まで改善

## 5. 準備完了時

すべてのチェックが完了したら、main へのコミット準備完了：

```bash
git add .
git commit -m "..."
```

---

**ポイント：**
- 検証は **人間が指示** → Claude Code が自動実行
- MUST 指摘は必ず対応
- SHOULD 指摘は判断で対応
- 最終確認は人間が行う
